Test pages

Open the same page as source and as target. Every page keeps an activity table of what it received, so the two tabs can be compared row by row.

Basic level 1

Text, email and password fields, select, textarea, toggles, radios, buttons. Hover state, focus rings, window and inner scrolling.

Iframes level 2

A payment frame with a nested terms frame inside it, plus a second frame without an id. Switch the payment frame to another origin with ?frame=.

Hard cases level 3

Custom dropdown, tabs, dialog, drawer, tooltips, contenteditable, keyboard shortcuts, filtered lists, dynamic rows, sortable table, shadow DOM.
