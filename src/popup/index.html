MirrorTab mirrors DOM interactions: clicks, inputs, keystrokes and scrolls from a Source tab to one or more Target tabs in real time. Perfect for demos, testing and live presentations.

  • Enter a Source URL and at least one Target URL.
  • Click Start Session, the tabs open automatically.
  • Interact with the SOURCE tab, actions mirror live to every TARGET tab.
  • Use Pause / Resume or Stop to control the session.
  • Download the event log as JSON or Text any time.
